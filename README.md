# Minimalist-bank-web-page-vanilla
Using advanced DOM manipulation in JavaScript to build a fully interactive bankist webpage

##  Key Features
* A slider component.
* Lazy loading images for efficient web loading.
* A tabbed component.
  

## Tech Stack
* **Language:** Vanilla JavaScript (ES6+)
* **Styling:** CSS3 
* **Markup:** HTML5


##  Things I studied from building this project. 

* **Selecting, creating, handling and deleting elememts:**  Using query methods, I sam able to select DOM elements and listen for events or perform some operations on them such as deleting them.
* **DOM traversing:** I can select parent and child elements by traversing by traversing through the DOM tree.
* **Event Delegation:** Implemented efficient event handling during the bubbling and capturing in the DOM.
* **Using the  intersection observationAPI:** I implememted this in parts where the user has to scroll to a section.
